# IMAL Infrastructure Monitor

A lightweight infrastructure monitoring dashboard for IMAL application servers.

## Features

- API health monitoring
- SSH connectivity checks
- CPU utilization
- Memory utilization
- Disk usage
- Filesystem monitoring
- Load average
- Uptime
- Automatic scheduled monitoring
- Manual refresh
- Docker deployment
- Multi-server support
- No database required

## Tech Stack

- Python
- FastAPI
- Jinja2
- Paramiko
- APScheduler
- Docker
- HTML/CSS/JavaScript

docker compose up -d
